# RISC-V Ottawa presentations

[![CC BY-SA 4.0][cc-by-sa-shield]][cc-by-sa]

Archive of presentations given during RISC-V Ottawa meetups.

Each presentation lives in its own folder named `<date>-<presenter-name>-<presentation-name>`
(date as `YYYY-MM-DD`), so the slides stay self-contained and easy to find.

Example:
```
presentations/
  2026-06-17-yusef-inaugural-status-update/
    slides.pdf          # the deck as a PDF
    slides.typ          # optional: the deck source code (if applicable), e.g., LaTeX, PowerPoint, Typst, etc
    images/             # optional: logos and images used by the deck
```

Keep each deck's assets in its own `images/` folder rather than referencing
files elsewhere in the repo, so a presentation can be moved or shared on its
own.
